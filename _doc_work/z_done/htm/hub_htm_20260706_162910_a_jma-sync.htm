jma 동기화 + 설치 완료

📁 fCapture 🆚

fCapture 프로젝트를 jma 머신에 동기화하고, jm4와 동일한 구성(brew 설치 + symlink + 설정파일)으로 설치를 완료했습니다.

수행 내역

단계내용결과
1. 프로젝트 rsync~/_git/__all/fCapture/ 전체 → jma 동일 경로. .gitignore 파일과 gitignore 대상 파일(Issue.md, noteForHuman.md, GEMINI.md 등)까지 포함. 빌드 캐시(.build/ 704MB)만 제외완료 (~273MB)
2. brew tap 복구jma의 finfra/tap이 remote 없는 수동 생성 잔재(초기 커밋 고정)여서 fcapture.rb가 없었음 → origin 추가 후 origin/main(abcc002)으로 reset완료
3. brew 설치brew install finfra/tap/fcapture → 1.0.18. 기존 깨진 symlink ~/.bin/fCapture → /opt/homebrew/bin/fcapture가 자동 해소됨1.0.18 확인
4. 설정파일 동기화jm4의 ~/.fCapture/ 설정 7종을 jma로 미러링. jm4에 없는 config.json 삭제, 구버전 defaultRegion.json 갱신, default.Scroll.json 신규 복사완료

보존한 항목 (머신 로컬)

  • ~/.fCapture/info_stateManager.json — 머신별 ID 카운터 상태파일이므로 덮어쓰지 않음
  • ~/.fCapture/jm4/, ~/.fCapture/jma/ — 캡처 산출물 폴더는 그대로 유지

검증 결과

$ ssh jma.local '~/.bin/fCapture --version'
fCapture 1.0.18

$ ssh jma.local 'cd ~/_git/__all/fCapture && git log --oneline -1'
f433ea9 .   ← jm4 HEAD와 동일
참고 1 — 화면 녹화 권한: jma에서 첫 캡처 실행 시 macOS 화면 녹화(Screen Recording) 권한 승인이 필요할 수 있습니다. SSH 원격으로는 승인 불가하므로 jma에서 직접 1회 실행해 주세요.
참고 2 — graphify-out/: jma의 git status에 graphify-out/이 untracked로 표시됩니다. jm4에서는 글로벌 gitignore로 제외되는 것으로 보이며, jma에는 해당 글로벌 설정이 없는 차이입니다. 동작에는 영향 없습니다.
