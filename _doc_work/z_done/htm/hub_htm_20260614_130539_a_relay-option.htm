fCapture — --relay 지연 캡처 옵션 추가 (Issue20)

📁 fCapture 🆚 세션 🎯📊

개요

--relay N 옵션을 추가했습니다. 이 옵션을 주면 fCapture가 캡처를 즉시 실행하지 않고 N초 동안 대기한 뒤 캡처합니다. 메뉴를 펼치거나 창을 전환하는 등 캡처 직전에 화면을 준비할 시간을 확보하기 위한 기능입니다.

사용법

fCapture --relay 3                       # 3초 지연 후 기본 설정으로 캡처
fCapture --relay 3 -t window_active      # 3초 지연 후 활성 윈도우 캡처
fCapture --relay 2 -t screen:1 -p /tmp   # 2초 지연 후 screen:1 을 /tmp 에 저장

지연 시간은 0 이상의 숫자(초 단위)이며 소수점도 지원합니다(예: --relay 1.5). 모든 캡처 모드(프리셋 플래그·config 파일·CLI 옵션)에 공통으로 적용됩니다.

동작 흐름

relay는 캡처 설정(config)의 일부가 아니라 런타임 modifier로 설계했습니다. 따라서 어떤 캡처 모드를 쓰든 캡처 실행 직전에 한 번 지연이 끼어듭니다.

인자 파싱 (--relay N)
   ↓
baseConfig 결정 + mergeConfig
   ↓
relay > 0 이면  →  "N초 후 캡처를 실행합니다..." 로그 + Thread.sleep(N)
   ↓
performCapture(config)   ← 실제 캡처
