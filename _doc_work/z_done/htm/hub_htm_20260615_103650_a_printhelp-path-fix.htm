printHelp -p 기본값 안내 오류 수정

📁 fCapture 🆚 세션 🎯📊

문제 요약

fCapture -h 의 도움말에서 -p / --path 옵션의 저장 경로 기본값이 ~/Pictures 로 잘못 안내되고 있었습니다. 그러나 실제 코드의 fallback 저장 경로는 시스템 데스크톱(~/Desktop)입니다. 사용자가 도움말만 보고 캡처 결과물을 ~/Pictures 에서 찾으면 파일이 없어 혼란이 발생합니다.

원인 분석

도움말 출력 경로는 두 갈래입니다.

출력 경로위치기존 안내실제값
번들 Usage.txt (정상 빌드 시 실제 출력)fCapture/Usage.txt:20~/Desktop~/Desktop
printHelp() 하드코딩 fallback (번들 누락 시)ScreenCaptureApp.swift:985~/Pictures~/Desktop
실제 저장 경로 결정determineSavePath() :2028, :2033—desktopDirectory = ~/Desktop

번들 Usage.txt 는 이미 올바른 값(~/Desktop)이었으나, 번들 리소스 로드 실패 시 사용되는 printHelp() 내부 하드코딩 문자열만 과거 오기(~/Pictures)가 남아 있었습니다. 두 출처가 불일치한 상태였고, _doc_arch/Glossary.md 에는 이미 "help 텍스트의 ~/Pictures 는 부정확"이라는 메모가 기록되어 있었습니다.

수정 내용

1. 코드 — ScreenCaptureApp.swift:985

- print("  -p, --path <path>         저장 경로 (기본값: ~/Pictures)")
+ print("  -p, --path <path>         저장 경로 (기본값: ~/Desktop)")

2. 설계 문서 — _doc_arch/Glossary.md:85

불일치를 지적하던 메모를, 양쪽이 일치하도록 수정되었음을 명시하는 문장으로 갱신했습니다.

- 미지정 시 시스템 Desktop(~/Desktop) 사용. (help 텍스트의 "기본값 ~/Pictures" 는 부정확 — 실제 fallback 은 Desktop.)
+ 미지정 시 시스템 Desktop(~/Desktop) 사용. CLI help(printHelp fallback·번들 Usage.txt) 와 코드 fallback 모두
+ ~/Desktop 으로 일치 (과거 printHelp fallback 의 "~/Pictures" 오기 수정됨).
